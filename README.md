# analysis-template

analysis-template provides a template for new analysis repositories.

## Instructions

In order to create a new analysis repository the user should

1)  Go to the analysis-template [GitHub
    repository](https://github.com/poissonconsulting/analysis-template)
    and choose ‘Use this template’.
2)  Clone the new repository.
3)  Rename `analysis-template.Rmd` to the name of the new repository.
4)  Confirm `run-all.R` runs without any errors.
5)  Commit and push the changes to the new repository.
6)  Delete the following line in `header.R`

<!-- end list -->

    project <- "analysis-template" # so runs with new working directory
